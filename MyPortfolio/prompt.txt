# Professional Prompt – Redesign Authentication (Login & Register) Pages

You are a Senior ASP.NET Core MVC Frontend Engineer, UI/UX Designer, and CSS Architecture Expert.

First, analyze the entire repository and understand the authentication layout, shared layouts, partial views, CSS files, JavaScript, Bootstrap grid system, and responsive behavior before making any modifications.

Repository:
https://github.com/MohamedSaber2004/MyPortfolio

## Objective

Completely redesign the **Login** and **Register** pages to achieve a premium, modern, responsive authentication experience.

The current authentication pages suffer from severe layout issues, including:

* Excessive width
* Broken margins
* Incorrect padding
* Poor content alignment
* Forms stretched across the full screen
* Weak visual hierarchy
* Inconsistent spacing
* Large empty areas
* Generic Bootstrap appearance

Fix the **root cause** instead of applying CSS overrides.

---

# 1. Authentication Layout

Replace the current full-width form with a professional centered authentication layout.

Create a maximum content width of approximately **1100px** and center it horizontally and vertically.

The layout should be:

```
--------------------------------------------------------
|                    Authentication Card               |
|------------------------------------------------------|
| Left Side (Branding) | Right Side (Login/Register)   |
|                      |                               |
| Logo                 | Form Title                   |
| Short Description    | Subtitle                     |
| Features             | Inputs                       |
| Illustration         | Buttons                      |
|                      | Links                        |
--------------------------------------------------------
```

The authentication container should never span the entire browser width.

---

Implement a consistent spacing system using an 8px scale:

* 8px
* 16px
* 24px
* 32px
* 48px
* 64px

Ensure consistent:

* Page padding
* Card padding
* Input spacing
* Button spacing
* Section spacing

Remove arbitrary margin and padding values.

# 3. Center the Authentication Card

The login and register card should:

* Be horizontally centered
* Be vertically centered (or near center on smaller screens)
* Have proper spacing from viewport edges
* Maintain a balanced layout on all screen sizes

Avoid stretched forms.

---

# 4. Improve Form Width

Current issue:

The inputs stretch almost the entire browser width.

Fix by:

* Limiting form width
* Using proper Bootstrap grid columns
* Creating comfortable reading width
* Improving whitespace

Redesign the authentication card with:

* Rounded corners (16–20px)
* Soft shadow
* Glassmorphism or subtle dark surface
* Thin border
* Modern background
* Smooth hover effect

The card should feel like a premium SaaS product.

The final Login and Register pages should resemble the authentication experience of modern SaaS platforms such as **Vercel**, **Linear**, **Stripe**, **GitHub**, or **Clerk**—with a centered authentication card, balanced spacing, refined typography, modern animations, and a polished, production-ready design that feels professional rather than a default Bootstrap form.
